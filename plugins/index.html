In the Hermes Agent plugin catalog

These are the plugins we run on our own agents, reviewed and accepted into the Hermes Agent plugin catalog. Each has a different job and limit.

How the system works for a founder: The operator layer.

plugins6 accepted, Oct 29 to Nov 9, 2026

  1. tripwire 0.1.3

    merged Oct 29, 2026 · updated Nov 9, 2026

    Writes down every action an agent was refused, so the owner gets one short alert instead of finding out later.

    install hermes plugins install tripwire

    tripwire codePR #145692PR #151041

  2. handydandy 0.4.1

    merged Nov 2, 2026 · updated Nov 8, 2026

    Tells you when a session has run long and can have the agent write a handoff, so the next session starts clean.

    install hermes plugins install handydandy

    handydandy codePR #146647PR #148914

  3. hermes-axioma 0.3.1

    merged Nov 5, 2026 · updated Nov 9, 2026

    Axiōma: marks the few phrases in an agent's reply that deserve a second look. It advises; it never approves anything.

    install hermes plugins install hermes-axioma

    hermes-axioma codePR #149364PR #151033

  4. hermes-standing 0.1.2

    merged Nov 9, 2026

    A worker's proven record sets what still needs the owner's approval; a task is not done until a check Standing ran itself passes.

    install hermes plugins install hermes-standing

    hermes-standing codePR #150366

  5. hermes-gatekeeper 0.1.0

    merged Nov 9, 2026

    Owner-configured policy checks on recognized outbound messaging calls; it does not inspect connector, MCP, browser or script sends.

    install hermes plugins install hermes-gatekeeper

    hermes-gatekeeper codePR #151074

  6. hermes-axiom-agent 0.1.0

    merged Nov 9, 2026

    Adds the nine-article Axiom Doctrine to each model turn and reports which enforcers are loaded and enabled; it enforces nothing itself.

    install hermes plugins install hermes-axiom-agent

    hermes-axiom-agent codePR #151218
